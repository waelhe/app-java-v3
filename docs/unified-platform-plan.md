# خطة المنصة الموحدة — الباك اند الكامل متعدد الأدوار (الطبقات 53+)

> **الحاكمة لبناء الطبقة الموحدة التي تجعل الباك اند منصةً كاملة الأدوار والوظائف والمزوّدين — وتجهّز كل ما يحتاجه مطوّر تطبيق الجوال عقداً وواجهةً وجلسةً.** مُصمَّمة بأمر المالك (2026-10-05): «تصميم خطة تنفيذية لتقوية الباك اند java spring boot and maven. ولتصل لمستوى بنية تحتية وعمارية متقدمة لتصبح منصة وتجربة المستخدم ui/ux الكاملة end to end بمستوى منصة متعددة الأدوار والوظائف والمزودين… واريدك ان تصمم خطة تنفيذية متكاملة لتجهز كل مايحتاجه مطور تطبيق الجوال. وبالنسبة لتخزين الجلسات، فأريدها حسب الاجراء العالمي. وان لاتنتهي الجلسة بدون تسجيل الخروج كما في التطبيقات والممارسات العالمية» — بنصه الكامل في §1.0.
>
> **النمط:** هذه الخطة التاسعة في عائلة الخطط الحاكمة (الأمن `docs/security/auth-system-redesign-plan.md`، العملاء والاستضافة، التوسع `docs/feature-expansion-roadmap.md`، أنظمة العقار `docs/realestate-systems-plan.md`، PostGIS `docs/postgis-integration-plan.md`، المجتمع `docs/neighborhood-community-plan.md`، مستوى Yelp `docs/governance/plans/yelp-level-plan.html`) — وتُبنى فوق حالتها النهائية المقيسة: **المجتمع مكتمل 12/12 طبقة** (L41-L52 — آخرها استطلاعات الرأي L52/#497)، **Yelp مكتمل بموجاته الست** (W0-W5 — آخرها الإعلانات والفوترة #496)، **العقار مكتمل 11/11** (L30-L40 + PostGIS)، خطة التوسع مكتملة، وحدة `marketplace-edge` (BFF) حية، والإنتاج يخدم رأس المصالحة على حساب v4 التجريبي. ترقيم الطبقات يكمل سلسلة SYSTEM.md §11 (آخرها 52).
