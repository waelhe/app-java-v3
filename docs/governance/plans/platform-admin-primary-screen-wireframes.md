# PAOS — Primary Screen Wireframes

**Status:** Structural UX specification; not a pixel-perfect visual design and not implemented UI.  
**Depends on:** [Detailed Screen and Interaction Specification](platform-admin-detailed-screen-specification.md) and [E2E Journey Recipes](platform-admin-e2e-journey-recipes.md).

These wireframes pin down the information hierarchy. Visual styling can evolve, but the labelled information, action sequence and safety behavior cannot disappear.

```text
├──────────────────┬──────────────────────────────────────────────────────┤
│ الرئيسية         │ صباح الخير — هذا ما يحتاج انتباهك                      │
│ العمل والقرارات  │ آخر تحديث: 09:42 | بيانات متأخرة في مصدرين             │
│ البحث            ├──────────────────────────────────────────────────────┤
│ الأعضاء والثقة   │ يتطلب تدخلك                                            │
│ المجتمع والسلامة │ [مرتفع] تراجع التوثيق في 3 أحياء [افتح المشكلة]        │

│ صحة المنصة       │ الطلب / الأثر / المدة  │ الحالة / المالك / الموعد    │
│ الإعدادات        ├────────────────────────┴─────────────────────────────┤
│ البيانات والأداء │ تجارب الأعضاء: التوثيق | النشر | البحث | الطلب | التنبيه│
```

**Contract:** a signal opens impact context and preserves the homepage state. A stale source gets an in-place warning. Missing telemetry cannot imply “healthy”. The first viewport prioritizes work and decisions, not raw infrastructure metrics.

```text
├─────────────────────────────────────────────────────────────────────────┤
│ ماذا يواجه الأعضاء؟ | ما نعرفه | ما نشتبه به | ما زال مجهولًا             │
├─────────────────────────────────┬───────────────────────────────────────┤
│ خطة المعالجة                    │ الأدلة والتسلسل الزمني                 │

├─────────────────────────────────┴───────────────────────────────────────┤
│ الإجراء المقترح: احتواء نطاق محدد | [راجع الأثر قبل التنفيذ]             │
├─────────────────────────────────────────────────────────────────────────┤

└─────────────────────────────────────────────────────────────────────────┘
```

**Contract:** confirmed facts and hypotheses are visually separate. The system will not infer that a recent change caused the incident without evidence. The close action lists any unmet exit criteria.

```text

الميزة: البحث عن الخدمات             السبب: [تراجع النتائج ▼]
النطاق:
  ( ) المنصة كلها
  (•) مدينة [برلين ▼] [كل الأحياء ▼]
  ( ) مجموعة أعضاء (عند وجود أهلية موثوقة)

الأثر المتوقع:
  18,420 عضوًا سيتأثرون (تقدير، آخر تحديث 09:40)
  سيتوقف: البحث عن الخدمات ضمن هذا النطاق
  سيبقى: تصفح المنشورات والملفات المحفوظة
  البديل: رسالة واضحة وروابط بديلة آمنة

فحص السلامة:
  ✓ الميزة مرتبطة بالمكونات المعروفة
  ! مكوّن لم يُختبر تأثيره بعد — يمنع التعميم حاليًا

[رجوع] [حفظ كمسودة] [التالي: راجع الأثر]
```

**Contract:** if any consumer is unverified, the production execution button stays disabled. Offer “افتح مهمة لفحص المكوّن” and “اعرض إجراء احتواء بديلًا” instead of a dead end.

## W05 — Payment exception

```text
ملف المشكلة المالية — الطلب #… | نتيجة الدفع غير محسومة

المبلغ المتوقع: 89.00 EUR      حالة الطلب: ينتظر تأكيد الدفع
رد مزود الدفع: لا توجد نتيجة نهائية موثوقة
السجل المالي: لم تتم المطابقة بعد
آخر فحص: 09:41

[افحص حالة الدفع] [اعرض تاريخ العملية] [اطلب مطابقة السجلات]

تنبيه:
لم نتأكد من النتيجة بعد. إعادة الدفع أو الاسترداد الآن قد تكرر العملية.
افحص الحالة أولًا؛ لا يوجد زر لإعادة العملية بشكل أعمى.

الخطوة التالية: فحص رد مزود الدفع ثم مطابقة السجل المالي.
المالك: فريق المالية     الموعد: خلال 15 دقيقة
[أنشئ/افتح ملف متابعة] [أحل للمراجعة المالية]
```

**Contract:** the refund path is unavailable until the authoritative source proves the payment is eligible and computes the amount/currency. The interface does not edit ledger balances.

## W07 — Review a setting change

```text
مراجعة التغيير قبل النشر

الإعداد: الحد الأقصى لمحاولات التسليم
الحالي: 3 محاولات          المقترح: محاولتان
السبب: تقليل التأخير في قناة متعثرة
النطاق: الرسائل غير الحرجة في برلين فقط

ما المتوقع؟
- يقل وقت إعادة المحاولة.
- قد تبقى بعض الرسائل الفاشلة دون محاولات إضافية.
- لا يتغير مسار التنبيهات الرسمية العاجلة.

- لا ينخفض نجاح التسليم عن الحد المتفق عليه.

- لا تزيد النتائج غير المؤكدة.

[عدّل المسودة] [أرسل للموافقة] [ألغِ]
```

**Contract:** the before/after comparison includes member-facing effect. Publishing is blocked if the “urgent alert unaffected” claim is not proven.


**Contract:** saving the form requests a grant; effective access only appears after the server confirms it and the authorization test passes.

## Responsive and accessibility behavior

- Desktop: full navigation and split list/detail views.
- Tablet: collapsible navigation; environment, scope and critical signal remain visible.
- Narrow screens: triage, acknowledgement, assignment and safe status/stop controls remain usable. Complex bulk/config/release authoring asks for a larger screen without discarding the draft.
- Keyboard: skip-to-content, visible focus, global search, predictable escape/back, navigable lists and accessible action menus.
- Screen reader: announce start/progress/partial/failure/verified-complete states; important messages also remain in page and activity history.
