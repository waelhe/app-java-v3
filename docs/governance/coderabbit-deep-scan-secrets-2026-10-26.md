## متابعة معلقة (موثقة بصدق)

الـblob يبقى في تاريخ git حتى إعادة كتابة منسّقة (`git filter-repo` على كل
المراجع) تُنفَّذ بعد هبوط الـPRs المفتوحة — إعادة الكتابة الآن تدمر #723/#732.
بعد هذا التغيير الزوج خامل (صفر مستهلكين)، وهو مكافئ التدوير لأثر dev لم
يثق به أي بيئة قط. عند هبوط الـPRs المفتوحة: `git filter-repo --path
marketplace-app/src/test/resources/keys/dev-rsa-private.pem --invert-paths`
على كل المراجع + دفع قسري منسّق، ثم التواصل مع دعم GitHub لتنقية المشاهدات
المخبأة (إرشادات GitHub الرسمية «Removing sensitive data from a repository»).
