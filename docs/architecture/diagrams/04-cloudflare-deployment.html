Hyperdrive
READY
Connection pooler + edge cache for external PostgreSQL (Neon).

R2 Storage
READY

External Managed Services
Cloudflare has no managed Postgres/Redis — use best-in-class serverless providers
Neon (PostgreSQL 17)
EXTERNAL
Serverless PostgreSQL with branching, autoscaling, point-in-time restore.
Free tier: 0.5 GiB storage • Connection via Hyperdrive
neon.tech • JDBC: jdbc:postgresql://...
Upstash (Redis 7)
EXTERNAL
Serverless Redis over HTTP/REST API (no persistent connections).
Use: Sessions, cache, rate-limit, TOTP replay guard, mfaToken store
upstash.com • spring.data.redis.url
Amazon SES
EXTERNAL
Transactional email relay (welcome, password reset, booking confirmations).
Alternative: SendGrid, Mailtrap (staging)
spring.mail.host=email-smtp.*.amazonaws.com
GitHub + Google OAuth
EXTERNAL
Social login providers (already configured in application.yml).
Callback: https://<host>/login/oauth2/code/{registrationId}
spring.security.oauth2.client.*
