Exception policy (PR #157): catch narrowed from Exception → DataAccessException. Programming errors (NPE, CCE) propagate to the event publication log → Spring Modulith marks the entry UNCOMPLETED → retry on next restart. Data-access failures (constraint violations) are logged but do not abort the batch.
